# Skills

Agent skills for Claude Code, Cursor, Windsurf, and other AI coding agents.

## Skills

| Skill | Description | Install |
|-------|-------------|---------|
| commit | Angular conventional commit format | `npx skills add Darmikon/skills --skill commit` |
| changelog | Generate PR changelogs from git diffs | `npx skills add Darmikon/skills --skill changelog` |
| rethink | Step back and rethink systematically after 3+ failed attempts at any task | `npx skills add Darmikon/skills --skill rethink` |
| better-docs | Optimize repository documentation and make AGENTS.md a lean routing file | `npx skills add Darmikon/skills --skill better-docs` |
| skill-publish | Create and publish skills to GitHub repos | `npx skills add Darmikon/skills --skill skill-publish` |
| focus | Shape output to be action-first and skimmable (manual-only) | `npx skills add Darmikon/skills --skill focus` |

## Install All

```bash
npx skills add Darmikon/skills --skill better-docs --skill changelog --skill commit --skill focus --skill rethink --skill skill-publish
```
